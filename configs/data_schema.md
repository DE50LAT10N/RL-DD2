# DD2 dump schema (target)

Expected folders in `%APPDATA%/DDRL/data`:
- `heroes/*.json`
- `monsters/*.json`
- `tokens/*.json`
- `items/*.json`
- `encounters/*.json`

Common fields:
- `id` or `Id`
- `name` or `Name`
- `Skills` (optional)
- `Heroes` / `Enemies` for encounters
- `MaxStacks` for tokens
